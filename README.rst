==========================
 Invenio-Previewer-Mirador
==========================

.. image:: https://github.com/turath-project/invenio-previewer-mirador/workflows/Tests/badge.svg
        :target: https://github.com/turath-project/invenio-previewer-mirador/actions

.. image:: https://img.shields.io/github/license/turath-project/invenio-previewer-mirador.svg
        :target: https://github.com/turath-project/invenio-previewer-mirador/blob/master/LICENSE

Invenio module that integrates the Mirador viewer as a previewer for digital objects within the InvenioRDM platform.

Features:

* IIIF manifest preview support
* Image preview support (jpg, jpeg, png, gif)
* Mirador 3.3.0 integration
* Configurable viewer options

Further documentation is available at: https://invenio-previewer-mirador.readthedocs.io/
